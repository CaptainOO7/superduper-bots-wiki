# 飞书任务与交付

适用版本：M1.5-01。

1. 在授权群中按管理员提供的格式提交需求，说明目标、允许修改的文件与可复验的结果。
2. 在同一讨论中回答澄清问题。检查冻结 Proposal 的版本、目标仓库、基础分支、受信测试和验收标准。
3. 由授权审批人在原讨论中明确审批精确版本。旧版本审批无法用于新需求。
4. 在同一讨论中查询进度。需要修订或取消时使用部署给出的控制指令，确认操作得到回执。
5. 在交付报告中核对候选 SHA、独立测试结果和 Draft PR。发布或合并由维护者决定。

Draft delivery keeps approval, testing, and repository review as separate steps.
