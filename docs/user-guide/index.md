# 飞书任务与交付

适用版本：SuperDuper Bots 0.2.0-rc.1 候选版。

1. 在授权群中用原生提及向 Bot 发送自然语言需求。收件回复确认已收到，审批仍需完成。
2. 对澄清消息使用逐条回复并给出可验证的结果。自然语言自动选择限于单一合规文件和覆盖该文件的登记测试；更广范围使用明确授权的结构化文件与测试。
3. 检查冻结 Proposal 的版本、目标 ID、固定提交、可写路径、受信测试和验收标准。审批者必须直接回复该条冻结消息，例如 `批准 P-1 v1`。
4. 在原讨论回复 `进度` 查看进度。若要取消，使用 `取消 P-1 v1`，并以当前版本为准。改过的消息若与原始事件内容不符，需发送新消息。已冻结的授权不会随编辑而改变。
5. 查看独立测试、Draft PR 和预览状态。以完整 SHA 比对原讨论、PR 头提交和预览显示。最新预览仍在等待或失败时，查看该 SHA 对应的 Wiki CI 和 Pages。

需要修订时，直接回复已验证的方案、交付或预览消息。更改范围或验收条件后，Bot 冻结新的 Proposal 版本，由审批者重新批准。成功后 Runtime Writer 在同一任务、分支和 Draft PR 上提交后继提交。远端已移动或 PR 已关闭时暂停交付。合并是维护者操作。

English search terms: draft pull request, preview commit, approval, revision, cancellation.
