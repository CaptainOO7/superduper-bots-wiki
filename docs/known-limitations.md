# 已知限制

适用版本：SuperDuper Bots 0.2.0-rc.1 候选版。

- 受管产品部署已在 macOS 验证。Wiki 的官方托管平台为 GitHub Pages。静态构建可移植。Wiki Docker 为可选资产，本候选版未验证其构建。
- GitHub 双 App 隔离、BigModel 和受控 Wiki 任务已通过现场验证。单 App、细粒度 PAT、匿名 Reader 和其他兼容模型端点使用夹具验证。只读探测无法证明 PAT 具备全部写权限。
- 自然语言发现仅检查已授权小型文本文件和已登记测试，最多建议两个可写文件。多文件路径使用离线夹具验证。匹配模糊和更复杂的请求需要澄清或由管理员核验结构化范围。
- 收到回复表示已收件。实际飞书网络、鉴权与 API 时延会影响响应。在已验证的网络路径和同类负载下，发布目标为原生确认 P95 不超过 5 秒，成功率至少 99%，验收样本无重复确认。持久化回执单独监控。原两秒目标未达成，保留为后续优化目标。实测共 100 条，来自单个会话，未主动测试冷鉴权。
- 在线预览是合格 Draft PR 的候选内容。使用完整提交 SHA 核验当前内容。外部 CI 或 Pages 暂不可用时，预览可能处于待核验或失败状态。
- 恢复旧持久数据前需要对账。工具保留已消耗的用量和已完成投递证据。
