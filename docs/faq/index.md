# 常见问题

## FAQ-001 为什么收到需求后没有开始执行？

适用版本：M1.5-01。检查原讨论中是否已有冻结的 Proposal，并确认授权审批人审核了当前版本。预期结果是收到审批回执。执行仍受仓库范围和额度限制。

## FAQ-002 Draft PR 会自动合并吗？

适用版本：M1.5-01。由仓库维护者在 GitHub 审查候选变更与 CI 结果。预期交付状态是 Draft PR。合并属于维护操作。

## FAQ-003 可以把产品源作为业务目标吗？

适用版本：M1.5-01。新部署应由管理员单独授权业务目标。不同仓库 ID 需要重新授权。仓库改名与仓库替换应分别处理。

## FAQ-004 如何区分服务已加载与服务健康？

适用版本：M1.5 候选版。运行 superduper-bots status。loaded 表示 launchd 已加载此服务。逐项查看 health 才能判断运行时、飞书和 GitHub 组件是否就绪。history 在有意暂停回填的部署中可以处于 paused。服务已加载本身不能证明消息接收和任务处理正常。

## FAQ-005 如何核对当前预览对应的提交 SHA？

适用版本：Wiki Pages 预览 M1.5-06 起。将原讨论交付消息中的完整候选 SHA、Draft PR 的当前头提交和预览页显示的候选提交逐字比对。三者一致后才按当前候选验收。预览待核验或核验失败时，查看当前 Draft PR 对应的 Wiki CI 和 Pages 检查，并在原讨论中等待或核对最新结果。旧 SHA 的预览仅作历史参考。
